# Visual asset provenance

The three workflow illustrations were authored for Alpha Research Wiki.
Their editable sources are in [docs/diagrams](../diagrams/README.md).
No diagrams, screenshots or prose were copied from the upstream starter.

## Design and logo

The illustrations follow the owner's Quantsera / Material 2 dark system.
The logo is an unchanged copy of the approved transparent, off-white
horizontal lockup: [quantsera-horizontal-transparent-offwhite.svg](quantsera-horizontal-transparent-offwhite.svg).
It is embedded as an image in each scene and preview, with its original
aspect ratio. It was not redrawn or recreated as text.

SHA-256 of the copied logo file:

```text

```

code/documentation license does not grant trademark rights.

## Fonts

SVG/PNG previews use Roboto Latin, normal 400 and 500, distributed by
`@fontsource/roboto` version **5.2.8**. Font files are bundled locally so
rendering does not depend on a remote font request.

- [Roboto 400](fonts/roboto-latin-400-normal.woff2)
- [Roboto 500](fonts/roboto-latin-500-normal.woff2)
- [SIL Open Font License and copyright notice](fonts/Roboto-OFL.txt)
- [Fontsource Roboto source](https://github.com/fontsource/font-files/tree/main/fonts/google/roboto)

The flow labels are English; the Thai explanations and accessible image
descriptions are in the [main README](../../README.md).
